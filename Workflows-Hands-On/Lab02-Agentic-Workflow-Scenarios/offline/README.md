# 오프라인 실습 자료 / Offline lab materials

GitHub에 접속할 수 없는 PC에서 실습할 때 사용하세요.
Use these when the lab PC cannot reach GitHub.

| 파일 | 설명 |
|---|---|
| `Workflows-Lab-Pack-KO.html` | **한국어판 (권장)** — 이미지 포함 단일 파일. 더블클릭하면 브라우저에서 열립니다. |
| `Workflows-Lab-Pack-EN.html` | 영문판 단일 파일 |
| `Workflows-Lab-Pack-KO.pdf` | 한국어판 PDF, 97쪽 |
| `Workflows-Lab-Pack-EN.pdf` | 영문판 PDF, 96쪽 |

## HTML을 권장하는 이유

실습 중에는 지시문·JSON 스키마·테스트 메일을 **정확히 복사해서 붙여넣어야** 합니다.
HTML은 코드 블록이 원본 그대로 복사되지만, PDF는 줄바꿈이나 들여쓰기가 깨질 수 있습니다.

HTML은 이런 것도 됩니다.

- 왼쪽 목차로 바로 이동
- 접이식 설명(토글)을 필요할 때만 펼치기
- 오른쪽 아래 **토글 모두 펼치기** 로 전체 내용 한 번에 보기
- 오른쪽 아래 **인쇄 / PDF** 로 직접 인쇄 (토글이 자동으로 펼쳐진 상태로 출력됩니다)

## PDF 참고

토글 24개를 모두 펼친 상태로 출력했으므로 접힌 내용이 빠지지 않았습니다.
다만 복사-붙여넣기는 HTML 쪽이 안전합니다.

## 배포

각 파일은 그 자체로 완결되어 있어 이미지 폴더를 함께 복사할 필요가 없습니다.
파일 하나만 USB나 메일로 전달하면 됩니다. (HTML 약 20MB, PDF 약 12MB)
